# デジタル名刺

QRコードで渡すWeb名刺。GitHub Pages で公開しています。

公開ページ: https://aizoon-jp.github.io/digital-meishi-tool/

## 中身

| 場所 | 中身 |
|---|---|
| `/` | 名刺ページ本体（1枚のHTMLで完結。縦画面での表示を基準に組んでいる） |
| `/tool` | 名刺ページを作るためのフォーム（入力 → 確認 → 完成の3画面） |
| `/aizoon_hp` | 名刺から辿る会社紹介ページ |

## 作り

- 素の HTML / CSS / JavaScript。ビルドもフレームワークも使っていない
- フォントは Google Fonts、それ以外の外部依存はなし
- 配信は GitHub Pages（`main` ブランチの `/` をそのまま配信）

名刺という用途では、読み込みが速いことと、数年後も手を入れられることが大事なので、
依存を増やさない作りにしています。
